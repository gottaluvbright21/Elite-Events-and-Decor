# Elite Events & Décor – WEDE020POE

## Project overview
A responsive multi-page website for **Elite Events & Décor**, a hypothetical event-planning organisation based in Cape Town, South Africa. The website is an academic demonstration and does not represent a registered business.

## Target audience
People planning weddings, birthdays and corporate events in the Cape Town area.

## Website goals
- Introduce the organisation and its services.
- Display event inspiration in an image gallery.
- Allow visitors to search available services.
- Provide enquiry and contact forms.
- Make information accessible on desktop and mobile devices.

## Pages
- `index.html` – Home
- `about.html` – Organisation information
- `services.html` – Services and search
- `gallery.html` – Image gallery and lightbox
- `enquiry.html` – Event enquiry form
- `contact.html` – Contact form and map

## Technologies
HTML5, CSS3 and JavaScript.

## How to run
Open `index.html` in a browser. For best results, use a local development server such as the VS Code Live Server extension.

## Important functionality notes
Form validation runs in the browser. The enquiry form is a demonstration and does not transmit or store data. The contact form prepares an email using the visitor's email application; replace the sample address with a real, authorised address before any real deployment. A genuine AJAX submission requires a server/API endpoint. The map and gallery images require an internet connection.

## SEO features
Each page includes a unique title, meta description, language declaration, responsive viewport and semantic HTML. Images include alternative text. Add verified organisation details and a sitemap/robots file if the site is deployed publicly.
