# Website Project Proposal

## Project name
Elite Events & Décor

## Organisation
Elite Events & Décor is a hypothetical event-planning and décor organisation based in Cape Town, South Africa. It provides planning and styling support for weddings, birthday celebrations and corporate events. This organisation is fictional and is used for the WEDE020POE academic project.

## Purpose of the website
The website will introduce the organisation, explain its services, show examples of event styling and make it easier for potential clients to enquire or contact the organisation.

## Target audience
- Individuals and families planning weddings or birthday celebrations.
- Businesses arranging conferences, launches or staff functions.
- People in Cape Town and nearby areas looking for event planning or décor support.

## Website goals
1. Present the organisation in a professional and clear way.
2. Explain the available event services.
3. Display visual inspiration through a gallery.
4. Allow visitors to search services.
5. Collect event enquiry details through a form.
6. Provide contact information and a location map.
7. Make the website usable on mobile phones, tablets and desktop computers.

## Proposed pages
Home, About, Services, Gallery, Enquiry and Contact.

## Design approach
The website uses a refined colour palette of deep navy, muted teal, warm cream and gold accents. It uses clear headings, readable text, consistent navigation and responsive layouts.

## Functionality
JavaScript is used for the mobile navigation, service search, image lightbox and browser-side form validation. The map is embedded on the contact page. A real online submission service would require a configured server or form-processing endpoint.

## Search engine optimisation
The pages use descriptive titles, meta descriptions, semantic headings, responsive viewport settings, descriptive links and alternative text for images. Content uses relevant phrases such as event planning, wedding décor and corporate events in Cape Town.
